# OneCard — Catalogue Management System

A complete **Product Catalogue Organization & Tiered Pricing Management System** built for OneCard's digital distribution business.

## What It Does

Transforms a raw, unorganized product catalogue (2,932+ products) into a structured commercial asset with:

- **Auto-classification** of every product by target country/region (20+ countries) and category (12 categories)
- **5-tier customer pricing** (Platinum, Gold, Silver, Bronze, Standard) based on 2 years of historical sales data
- **Coverage gap analysis** showing where product availability is strong vs. needs expansion
- **Interactive web dashboard** for browsing, filtering, and managing the entire catalogue

## Files

| File | Description |
|------|-------------|
| `catalogue_engine.py` | Core Python engine — reads raw catalogue + historical data, classifies products, tiers customers, generates outputs |
| `catalogue_dashboard.html` | Self-contained interactive web dashboard (6 tabs) |
| `catalogue_data.json` | JSON data powering the dashboard (auto-generated by engine) |
| `Organized_Catalogue_Master.xlsx` | 11-sheet structured Excel workbook (auto-generated by engine) |

## Quick Start

### 1. Generate Data
```bash
python catalogue_engine.py
```
This reads `Full Catalogue.xls` + historical sales data and generates both `catalogue_data.json` and `Organized_Catalogue_Master.xlsx`.

### 2. Launch Dashboard
```bash
python -m http.server 8080
```
Open `http://localhost:8080/catalogue_dashboard.html` in your browser.

## Dashboard Tabs

| Tab | Features |
|-----|----------|
| **Overview** | Key metrics, category chart, tier donut chart |
| **Product Catalogue** | Searchable/sortable/filterable table of all products with tier prices |
| **Country Explorer** | Country cards with coverage indicators, region filters, product drill-down |
| **Customer Tiers** | 5-tier segmentation with revenue, GP, and discount metrics |
| **Coverage Analysis** | Country × Category heatmap showing gaps and opportunities |
| **Price Calculator** | Instant tier pricing and margin analysis for any product |

## Customer Tiers

| Tier | Min Annual Revenue | Discount | Description |
|------|-------------------|----------|-------------|
| Platinum | SAR 10M+ | 4.0% | Top strategic accounts |
| Gold | SAR 3M+ | 2.5% | Major accounts |
| Silver | SAR 500K+ | 1.5% | Growing accounts |
| Bronze | SAR 100K+ | 0.75% | Regular accounts |
| Standard | < SAR 100K | 0% | Default pricing |

## Tech Stack

- **Engine**: Python 3 (pandas, openpyxl, numpy)
- **Dashboard**: Vanilla HTML/CSS/JS (self-contained, no dependencies)
- **Design**: Dark theme with glassmorphism, Inter font, responsive layout

## Customization

Edit `TIER_CONFIG` in `catalogue_engine.py` to adjust tier thresholds and discount percentages, then re-run the engine.
