# OneCard — Catalogue Management System v2

A complete **Product Catalogue Organization & Tiered Pricing Management System** built for OneCard's digital distribution business, specifically designed for onboarding and pricing **new customers**.

## What It Does

Transforms a raw, unorganized product catalogue (2,932+ products) into a structured commercial asset with:

- **Auto-classification** of every product by target country/region (20+ countries) and category (12 categories)
- **Margin-Sharing Pricing Model**: Sets customer tier pricing as a percentage of OneCard's own margin rather than face value. Customer discounts are funded directly by sharing a portion of OneCard's profit.
- **5 Configurable Pricing Tiers** (Diamond, Gold, Silver, Bronze, Starter) representing different levels of margin share.
- **Interactive Web Dashboard**:
  - **Overview**: High-level catalogue statistics and region/category distributions.
  - **Product Catalogue**: Advanced grid with multi-select filters, search, and sorting.
  - **Merchant Explorer**: Hierarchy-based browsing to inspect and extract catalogues by merchant.
  - **Country Explorer**: Drill-down view with multi-select support for countries and regions.
  - **Pricing Tiers**: A live UI editor allowing real-time adjustment of tier names, colors, and margin share percentages with instant catalog recalculation.
  - **Coverage Heatmap**: Grid mapping categories against countries to identify coverage gaps and opportunities.
  - **Price Calculator**: Interactive pricing tool showing Face Value, Cost, OneCard Margin, Customer Discount, and OneCard's remaining profit for any selected item.

## Files

| File | Description |
|------|-------------|
| `catalogue_engine.py` | Core Python engine — reads raw catalogue, classifies products, computes pricing, generates outputs |
| `catalogue_dashboard.html` | Self-contained interactive web dashboard (7 tabs) |
| `catalogue_data.json` | JSON data powering the dashboard (auto-generated by engine) |
| `Organized_Catalogue_Master.xlsx` | 11-sheet structured Excel workbook (auto-generated by engine) |

## Quick Start

### 1. Generate Data
```bash
python catalogue_engine.py
```
This reads `Full Catalogue.xls` and generates both `catalogue_data.json` and `Organized_Catalogue_Master.xlsx`.

### 2. Launch Dashboard
```bash
python -m http.server 9090
```
Open `http://localhost:9090/catalogue_dashboard.html` in your browser.

## Pricing Tiers (Default Config)

Under the margin-sharing model, the default tiers allocate OneCard's margin as follows:

| Tier | Margin Share % (To Customer) | OneCard Retained Margin | Description |
|------|------------------------------|-------------------------|-------------|
| **Diamond** | 60% | 40% | Maximum discount tier |
| **Gold** | 50% | 50% | High volume accounts |
| **Silver** | 40% | 60% | Mid-market accounts |
| **Bronze** | 30% | 70% | Starter partners |
| **Starter** | 20% | 80% | Default/new accounts |

*Note: All calculations are automatically floored at product cost to guarantee OneCard never sells at a loss.*
